B. VEP Stan inversion：每一步代码做什么

1

选择患者与唯一 seizure recording

入口 vbt.cli._infer() 启动 vbt.inference.reference_engine。引擎搜索文件名同时包含 simulatedseizure、VEPhypothesis、run-01 的 VHDR，并要求恰好一个。

输入
--subject sub-001、dataset root
方法
确定性文件筛选，不使用 truth
代码
reference_engine.main()
输出
selected seizure path；稍后写入 preflight.json
2

读取 BrainVision SEEG

read_brainvision() 解析 VHDR，读取 little-endian float32 EEG，根据每通道 resolution 缩放，返回 raw[time, channel]、采样率与有序通道名。

验证
MULTIPLEXED、IEEE_FLOAT_32、样本总数可被通道数整除
输出
raw、sfreq、channel_names
3

加载 SC、Gain，并对齐双极通道

read_connectome() 读取 weights.txt，对角清零并按全局最大值归一化。bipolar_gain() 对每个通道 A-B 构造 |G_B-G_A|。左右小脑 Gain 列被设为全 Gain 最小值。

SC ← SC / max(SC)； GainA-B = |GainB − GainA|

注意：这是 legacy Stan 路径的 absolute bipolar Gain；新 context-query 路径使用 signed bipolar Gain，两者不能混为同一观测模型。

4

SEEG → positive log-power feature

log_power_features() 不是直接拟合 raw SEEG。它依次执行：

  1. 逐通道将超过均值 ±2 SD 的点替换为均值；
  2. 三阶、零相位 10 Hz 高通；
  3. 前向100样本窗口计算均方功率并取 log；
  4. 再次做 ±2 SD 异常值处理；
  5. 三阶、零相位 1 Hz 低通；
  6. 按 stride 降采样到约 n_time=150；
  7. 整体平移，使最小值为1且全部严格为正。
输出
Obs[model_time, channel]
重要
Stan 内部实际使用 log(Obs) 作为 target
5

构造参数低维先验坐标

代码对双极 Gain 做完整 SVD：_, _, vh = svd(gain)，然后 eig = vh.T。Stan 用它把标准正态 x0_star 映射到162 ROI excitability：

x0 = −3.0 + 0.30 · eig · x0_star

这不是 SC graph eigenbasis，而是 Gain 的右奇异向量基；名称 eig 容易误解。

6

序列化并做输入 QC

rdump() 写出 Stan 所需 stan_data.R；同时保存 prepared_inputs.npz、四联图 input_qc.png 和带 SHA-256 的 preflight.json。

检查
SC=(162,162)、Gain=(channels,162)、所有数组 finite、Obs>0
盲性
此阶段不读取 x0/EZ truth
7

Stan 内部 forward model

每一个候选参数都通过相同的二状态 Reduced Epileptor Euler forward：

dx = 1 − x³ − 2x² − z + I₁
dz = [4(x − x0) − z − K·ΣⱼSCᵢⱼ(xⱼ−xᵢ)] / τ₀
x(t+1)=x(t)+0.1·dx；z(t+1)=z(t)+0.1·dz

冻结常数：dt=0.1、tau0=15、I1=3.1。Sensor prediction：

x̂(t) = amp · Gain · x(t) + u

从第10个 model-time block 之后使用 Gaussian likelihood：log(Obs) ~ Normal(xhat, eps)。

8

Inversion：MAP 或 NUTS

MAP

CmdStan L-BFGS 多起点优化。按 lp__ 选最优解，输出单个 x0 point estimate。

代码：optimize algorithm=lbfgs，结果 prediction_map.csv。

NUTS

先用多起点 L-BFGS 选若干好初值，再运行多链 HMC/NUTS，输出 posterior draws。

必须检查 R-hat、divergence、treedepth、BFMI、NaN rejection；运行成功不等于收敛。

Stan 同时估计/变换 x0、初始 z、coupling K、sensor amplitude、offset u 与 noise eps。

9

形成两种不可混称的盲 ROI 排名

参数型：prediction_blind.csv 用 posterior mean x0 从大到小排序，表示较高 excitability。传播型：source_ezn_blind.csv 对每个 Stan posterior draw 的二维 Epileptor x 找首次 x>0；从未越界记为 onset=200，再按 Wang 等 2025 的公式计算 draw 内归一化 EV，最后跨 draw 汇总。

tᵢ = first{t:xᵢ(t)>0}，否则200； EVᵢ = −log(((tᵢ−min(t))+1)/20)，每 draw 归一化到[0,1]

同时输出 onset 5/50/95% quantile、recruitment probability、EV quantile 和并列感知 rank。VEP 自带六维 source 文件是 x2−x1，不是这个二维 x，不能直接套用该阈值。

10

Truth unlock 与 EZN 评价

07c_unlock_truth_and_evaluate.py 先核对 blind prediction SHA-256 未改变，再读取参数 TSV 中的 EZ 列表。vbt.evaluation.ezn.evaluate() 计算 AUROC、tie-grouped AUPRC、first/mean EZ rank、fractional Recall@真实EZ数。

Truth unlock 只允许写 evaluation 输出，不能反向启动 inference 或修改 prediction。

C. “找到参数后开始 forward”在当前代码中是什么意思？

Stan inversion 内已发生

解释已观测 seizure

Forward 是 likelihood 的组成部分。优化器或 NUTS 每提出 (x0,K,z_init,amp,u,eps)，Stan 就重新积分 source states，再投影到 SEEG，与 Obs 比较。因此 inversion 结束时已经完成大量 forward。

已导出但被有效性门控

后验 source trajectory

Stan 已在每个 posterior draw 的 generated quantities 中重新积分 x[region,time]。新增脚本流式读取这些列并导出 onset/recruitment/EV；它不是另起一个不同方程的 replay。只有采样诊断通过且确实出现 source recruitment 时，传播排序才可解释。

context-query API 已实现

预测新 condition

predict_query() 用拟合的 x0,K 新建 ReducedEpileptor，带 query 的 initial state/stimulation 重新 simulate()，再做 signed Gain 投影。

VEP cohort 被门控停止

但不能对 VEP 宣称成功

Fisher/OED v2 的18个 fold 只有约2个有效参数方向，低于预注册门槛10。因此 oracle 未解锁、VEP graph MAP 未运行、protocol v3 被禁止。

G. ROI onset、排序与 EZ/PZ：实际跑通后的结论

工程闭环 PASS

30/30 可生成逐 ROI 输出

每例读取2条短链、共10个 draws；盲导出后才解锁 truth，预测 CSV 的 SHA-256 在评估前后完全一致。输出覆盖162个 ROI 的 onset quantile、招募概率、EV quantile 和 tie-aware rank。

科学门 FAIL

posterior 不可用于可信定位

30/30 患者均为 FAIL_DIAGNOSTICS；只有10/30出现任何 x>0 的 ROI，20/30没有任何招募。无招募时全部 EV=0、并列 rank=81.5，不存在可解释的 onset 顺序。

目标Macro AUROCMacro AUPRCRecall@真实阳性数首个阳性 rank
EZ（30例定义）0.5340.0950.090均值68.6；中位81.5
PZ（17例定义）0.6010.1670.164均值58.6；中位81.5

这些数值不能作为模型识别能力证据。它们来自每链5 draws 的 engineering smoke，所有病例的 NUTS 诊断均失败，而且多数病例没有论文定义下的招募。可信下一步不是调 x>0 阈值，而是用足够长的模型时间窗和完整 NUTS 配置重新反演，并同时通过 convergence gate、posterior recruitment gate 和冻结盲评估。

正确解释

这是 excitability 定位，不是传播恢复

主 EZN score 是反演得到的 x0。模型对本患者 EZ 定位很好，但 PZ 和 onset 失败，因此不能声称已恢复完整 seizure propagation，也没有 posterior uncertainty。

单患者结论：从观测信号开始，经由反复 forward 的多起点 MAP inversion，到冻结的患者参数和 EZN 排名，这条链已经真实跑通；在 sub-001 synthetic case 上取得较好 EZ 结果且8个起点高度一致。该成功不依赖 population model，但仅是一例 synthetic demonstration。

最后用一句话顺一遍

当前单患者成功路径：sub-001 synthetic SEEG/SC/Gain → 文件与shape校验 → SEEG log-power → Stan 二状态 simulator 在每次 L-BFGS 更新中重新 forward → 8起点选择观测目标最优解 → 冻结162 ROI x0 排名 → 才读取 EZ/PZ truth。EZ定位通过预设门；PZ、source onset、posterior uncertainty、cohort和临床有效性仍未完成。
